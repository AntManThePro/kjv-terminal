# KJV Reader

Public-domain King James Bible. One chapter at a time.

No account. No streak. No ads. The name is the contents.

## Open

https://antmanthepro.github.io/kjv-terminal/

Matthew 1 starts the New Testament. Genesis is one tap. Tap the green chapter bar to pick a number.

Matthew 1 and Genesis 1 live in the page so they open even as a downloaded file. Other chapters need a connection the first time, then they stay on the phone.

## Use

- Previous / Next turns the page
- Choose a book lists all 66
- Tap a verse twice to sit with only that verse
- Read aloud speaks the chapter, or the one verse if you are sitting with it
- More has bigger words and a notebook
